# Sales Performance Analysis (Excel + SQL)

## Overview
This project analyzes sales data using SQL for querying and Excel for dashboard visualization.

## Tools Used
- SQL (MySQL)
- Microsoft Excel
- Pivot Tables & Charts

## Key Analysis
- Total sales by category
- Monthly and hourly sales trends
- Top performing products

## Files
- excel/Sales_Dashboard.xlsx – Interactive Excel dashboard
- sql/SQL_Queries.docx – SQL queries used for analysis
